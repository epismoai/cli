# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.
Use [GitHub's private vulnerability reporting](https://github.com/epismoai/cli/security/advisories/new) instead. Include a clear description, affected versions, reproduction steps, and any suggested mitigation.

We aim to acknowledge reports within five business days and will coordinate a fix and disclosure timeline with the reporter.

## Supported versions

Security fixes are applied to the latest released version of the CLI. Users should upgrade to the newest release.
